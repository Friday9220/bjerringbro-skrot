# Bjerringbro Skrot & Afhentning

Hjemmeside for Bjerringbro Skrot & Afhentning: gratis afhentning af jern og metal, gamle møbler, hvidevarer, rydning af huse og garager og hjælp til flytning i Bjerringbro og omegn.

Siden er ren HTML og CSS uden byggetrin. Åbn `index.html` i en browser for at se den.

## Før siden går live

Søg efter `PLADSHOLDER` i `index.html` og udskift:

- **Messenger-link**: `https://m.me/PLADSHOLDER` (4 steder) → fx `https://m.me/ditbrugernavn`
- **Telefon**: `tel:+4500000000` og `+45 00 00 00 00`
- **E-mail**: `kontakt@example.dk`

## Udgivelse

Siden kan hostes gratis med GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
